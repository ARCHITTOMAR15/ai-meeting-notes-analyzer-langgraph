
# AI Meeting Notes Analyzer using LangGraph (RAG + Agentic RAG)

Production-ready AI Meeting Notes Analyzer built using LangGraph, LangChain, LlamaIndex, FAISS, Hugging Face LLM, and Streamlit.

## Tech Stack

- LangGraph
- LangChain
- LlamaIndex
- FAISS
- Hugging Face
- Streamlit
- Pytest

## Dataset

Meeting transcript provided in `data/raw/Meeting_Transcript.txt`.
